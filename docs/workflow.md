# 《中国古代史教程》EPUB 制作约定

本项目把扫描版《中国古代史教程》（朱绍侯主编、龚留柱执行主编，河南大学出版社 2010 年 8 月第 1 版，上下册）制作成 EPUB 3。**正文文字以已精校的 TXT 为唯一来源**（`ocr/chNN.txt`），**排版与脚注以 PDF 原书为准**。

## 目录结构与素材

- `ocr/ch00-preface.txt` — 前言（含编写分工名单）
- `ocr/ch01-inline.txt` … `ocr/ch10-inline.txt` — 十章正文转换原料（脚注已内联为 `^[…]`；由 `ocr/chNN.txt` 经 `scripts/inline-footnotes.py` 生成，chNN.txt 中章末注文列表已剥离）
- `ocr/ch01.txt` … `ocr/ch10.txt` — 精校 TXT 分章原稿（含章末注文列表，备查）
- `ocr/toc.txt` — 原书目录（仅供核对章节结构，不直接进入书稿）
- `source/upper.pdf` — 上册扫描件（436 页），含第 1–5 章
- `source/lower.pdf` — 下册扫描件（483 页），含第 6–10 章
- `ocr/mineru/chNN-pipeline.md`、`ocr/mineru/chNN-vlm.md` — MinerU 双模式 OCR 结果（按章切分；第一章与第二章合在 `ch01-02-*.md`）。**MinerU 会系统性漏收页底圈码注文，但正文中的圈码标记位置基本齐全**，表格识别为 HTML `<table>`（vlm 模式行列更准，仍可能有单元格串行）
- `manuscript/chNN.md` — 转换输出（pandoc Markdown，NN = 01…10；前置文件为 00-frontmatter.md、01-preface.md、02-inserts.md）

## 原书页码 ↔ PDF 页码换算

- 上册（第 1–5 章）：**PDF 页 = 原书页 + 15**（原书第 1 页 = PDF 第 16 页）
- 下册（第 6–10 章）：**PDF 页 = 原书页 − 410**（原书第 423 页 = PDF 第 13 页）

| 一 | 1–31 | 上册 16–46 |
| 二 | 32–105 | 上册 47–120 |
| 三 | 106–194 | 上册 121–209 |
| 四 | 195–327 | 上册 210–342 |
| 五 | 328–422 | 上册 343–437 |
| 六 | 423–526 | 下册 13–116 |
| 七 | 527–652 | 下册 117–242 |

渲染原书页面用 Ghostscript（已安装 `gs`）：

```bash
mkdir -p /tmp/pages-ch03
gs -dNOPAUSE -dBATCH -sDEVICE=png16m -r130 \
  -dFirstPage=121 -dLastPage=209 \
  -sOutputFile=/tmp/pages-ch03/page-%03d.png source/upper.pdf
```

输出文件名中的序号即 PDF 页码（`page-121.png` = PDF 第 121 页 = 原书第 106 页）。用 ReadMediaFile 查看。

**节省上下文的技巧**：核对脚注时不必看整页，渲染后用 ImageMagick 裁出页底约 1/4 区域再看：

```bash
magick /tmp/pages-ch03/page-121.png -gravity South -crop 100%x25%+0+0 +repage /tmp/pages-ch03/foot-121.png
```

核对正文版式（标题层级、引文缩进、表格）时才看整页。

## 标题层级

| 层级 | 内容 | 示例 |
|---|---|---|
| `#` | 章题（第 N 章 XXX） | `# 第三章 春秋战国` |
| `##` | 导读、第一节 … | `## 导读`、`## 第一节 人类的起源与进化` |
| `###` | 目（一、二、…） | `### 一、石器时代的文化遗存` |
| `####` | 小节（1. 2. …） | `#### 1. 元谋人` |
| `#####` | 小小节（（1）（2）…） | `##### （1）对𢀛方的战争` |

- 构建用 `--split-level=2`，所以 **每个 `##` 节另起一页**；不要在某节内容前手动加 `\newpage`。
- 章题下独占一行的年代行写成 span：`[（公元前770年～公元前221年）]{.niandai}`（居中、小字，落在章扉页）。
- TXT 中有的节标题缺空格（如`第一节人类的起源与进化`），转换时补上为`第一节 人类的起源与进化`。
- 目级标题 `### 一、` 会进入 EPUB 目录（toc-depth=3），`####`/`#####` 不进目录。

## 脚注（重点，必须对照原书核对）

原书脚注是**页底圈码 ①②③，每页重新编号**。精校 TXT 把它改成了「行内 `[n]` + 章末 `[n] 注文列表`」，已由 `scripts/inline-footnotes.py` 机械转换为 pandoc 行内脚注 `^[注文]`，**各章转换原料是 `ocr/chNN-inline.txt`**（正文脚注已就位，章末注文列表已剥离，共 1270 条，每章编号 1..N 一一对应，已程序校验）。

转换者要做的核对：

1. **标记位置核对（利用 MinerU）**：`ocr/mineru/chNN-pipeline.md` 与 `chNN-vlm.md` 正文中的圈码 ①②…（每页重新编号）位置与原书一致。把 MinerU 文本中每个圈码所在的句子，与 `ocr/chNN-inline.txt` 中每个 `^[…]` 所在的句子按顺序比对——两个序列应逐句对应。发现错位时渲染原书页裁决。
2. **注文文字核对**：MinerU 会系统性漏收页底注文，注文文字以精校 TXT 为底，但必须**渲染原书页底（magick 裁页底 25%）抽核**：每章至少核 20 条（章首、章中、章尾覆盖），发现 TXT 注文与页底注文有出入时以 PDF 为准改正；若抽核发现系统性问题则全章逐条核对。
3. 脚注文字内的引号、书名号、「参见」「以上参见」等措辞照录原书。
4. 自查：`grep -c '\^\[' manuscript/chNN.md` 必须等于该章注文总数；不得残留 `[n]` 形式标记。

## 表格与世系表

原书章末附两类表：

1. **边框表格**（如「中国史前时代简表」「十六国简表」）：TXT 中为 tab 或多空格分隔，且**列对齐已被 OCR 破坏**（如「成一汉」实为「成—汉」、「奴」实为「匈奴」）。可先参考 `ocr/mineru/chNN-vlm.md` 中的 HTML `<table>`（行列结构较好但单元格可能串行），**最终必须渲染原书对应页核对每个单元格文字**。
   - 用 pandoc pipe table 输出；不使用合并单元格，原书跨列的分段行（如「西晋末年建立的两国」）写成第一列有字、其余列留空的普通行。
   - 原书跨页表格的「（续表）」标记删除，合并为一个表。
   - 表题独占一行：`[中国史前时代简表（170万年前～公元前21世纪）]{.biaoti}`（加粗居中）。
2. **链式世系表**（如「（1）禹——（2）启——……」）：TXT 中已是完整单行。表题用 `[…]{.biaoti}`，链式内容包在 fenced div 里：

   ```
   ::: {.shixi}
   （1）禹——（2）启——（3）太康——……
   :::
   ```

3. 表格/世系表内的年代范围符号统一为全角 `～`（TXT 中混用了 `~` 和 `-`，如`（626-649）`改为`（626～649）`）。

## 引文与其他版式

- 正文中**单独成段的古文引文**（原书缩进排，如《史记》《诗经》引文）用 Markdown blockquote（`> `），EPUB 中渲染为楷体缩进块。是否属于此类引文拿不准时渲染原书页确认。
- 卦象符号（⚊⚋☰ 等）、生僻古字（𢀛、𫩻 等）一律照录，不得替换为图片或谐音字。
- 扫描件上的前人手写批注一律忽略，不入书稿。
- 原文文字一律照录精校 TXT，不润色、不改写、不增删；TXT 与 PDF 冲突处以 PDF 为准。
- 段落之间空行分隔；删除 TXT 行内的多余全角空格、tab。

## 输出与自查

每章输出一个文件 `manuscript/chNN.md`（NN = 01…10），文件开头第一个非空行必须是 `# 第N章 章题`。完成后执行：

```bash
grep -n '\[[0-9]' manuscript/chNN.md        # 必须无输出（脚注无 [n] 残留；注意 ^[1980年…] 这类以数字开头的注文是误报，需人工看一眼）
grep -n "$(printf '\t')" manuscript/chNN.md # 必须无输出（无 tab；macOS 的 grep 没有 -P）
grep -o '\^\[' manuscript/chNN.md | wc -l   # 必须等于该章注文总数（一行多注时 grep -c 会少数，必须用 -o）
```

各章注文总数：ch01=7，ch02=42，ch03=135，ch04=256，ch05=225，ch06=142，ch07=130，ch08=88，ch09=132，ch10=113。

不要运行 `make build`（全书未齐时构建无意义）；不要改动 `manuscript/` 以外的任何文件。
